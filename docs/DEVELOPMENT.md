受击不再大幅弯腰或长时间僵住：后撤约 7–11 个源图像素、身体短暂倾斜约 2.5 度，接入恼火握拳待机。命中约 0.2 秒后，头边弹出红色怒筋与两缕蒸汽，约 1.3 秒内淡出；下一次受击刷新，死亡、复起或胜利时移除。关闭 effects 或设强度为零会关闭怒气特效。

死亡采用 1.35 秒的前倒过渡，腿部向后伸展，最后接入专门绘制的趴地姿态并保持；复起会恢复所有正常显示层。趴地表情和静态终态是独立图片，落地过渡仍由骨骼和透明度曲线控制。

独立生成素材和完整提示词位于 `assets/sprites/puppet-*-v0.7.png` 与 `assets/prompts-v0.7.txt`。动作作者脚本为 `tools/puppet_rig.py`，`tools/make_rig.py` 是当前入口。`preview/attack-v0.7.gif` 与 `preview/death-v0.7.gif` 为原生姿态采样的软件渲染预览，不是游戏截图。

以下 0.4–0.6 章节为历史迭代记录，当前运行时结构以上述 0.7 为准。

## 0.6.0 肘腕、手掌与出手节奏

- 对照本机猎手模组的原生动画采样，参考约 0.567 秒攻击中的快速出手与较长回收；为 DeepSeek 娘重新编写曲线。
- 增加双侧肘部、手腕、指尖控制，现为 20 根骨骼、4266 个加权顶点、8268 个三角形；保留 22 段连续动画。
- 打击、横挥、连击与远程动作各有收手、送掌、转腕和回收。手掌相对身体产生实际位移，不仅随人物整体前移；动作结束回到原位。
- 施法与聚能加入抬手、翻腕、展掌，后手辅助蓄力；防御双手向内收拢，受击时手腕回撤，观察、备战、放松、冥想和庆祝也有轻微手部变化。
- 发尾和鲸尾在攻击中稍后跟随身体，原生动作混合从 0.14 秒调整为 0.10 秒，减少快速出牌时的拖沓感。
- 重新分配手部权重，限制裙摆跟随手掌被拉动的范围；独立引擎中以动作 120Hz、循环 60Hz 采样检查，无三角形翻面。该采样频率不是游戏帧率。

## 0.5.0 动作扩充、人物放大与基础卡分色

- 连续动画从 8 段扩充到 22 段：增加侧头观察、备战与放松待机、横挥、连击、远程出手、弧线施法、蓄力释放、撑盾、受击恢复、入场致意、冥想和挥手庆祝。
- 重复打击在三种动作间轮换，光束/炮击选择远程动作；防御、普通技能、能力牌和受击各有变化。仅使用人物自己的计数器，不调用游戏 RNG。
- 出牌后根据动作类别接入不同的待机循环；原生重复动作通知按动作类别去重，保留已选中的变体。
- 战斗主体默认高度从 260 增至 300（约放大 15%），脚底为缩放基准；选人立绘高度从 840 增至 920，并调整中心位置保持脚下落点。
- 单独重绘基础打击、防御插画：打击使用珊瑚橙红与琥珀冲击，防御使用翡翠青绿与薄荷护盾。人物蓝发、蓝白女仆服保留；卡框、标题、数值、升级、玩法均沿用原卡。
- 两张独立 PNG 通过卡面索引的 file 字段嵌入替换；其他 96 项有效卡面沿用原插画。

## 0.4.0 动画驱动基础

用户反馈 0.3.0 动画明显卡顿后，检查了已安装的猎手外观包 LieRenTVmod（创意工坊 3787753911）。该包使用 Spine 4.2.43 骨骼资源。旧版 DeepSeek 娘采用八张图片轮换，多帧停留 0.65 秒，换图还会改变轮廓；加快播放不能解决这个结构问题。

本版改用游戏自带的 **Spine 4.2 原生播放器**，为 DeepSeek 娘自行制作骨骼、网格权重和动画：

- 14 根骨骼、2100 个加权顶点、4018 个三角形，使用已批准的精修人物图作为纹理。
- 呼吸、轻微重心移动、手臂、发尾和鲸尾按不同相位连续运动；眼部局部网格收合实现眨眼。
- 待机、攻击、施法、防御、蓄力、受击、倒下、胜利共八段连续动画。
- 使用可连续求值的曲线，待机循环首尾衔接，移除整张待机图片的定时轮换和双层图片淡变。
- 由原生 Spine 处理约 0.14 秒的动作混合、动作打断和返回待机。骨骼随实际渲染帧更新，不人为限制为 8 FPS 或 10 FPS。
- 新卡牌可以开始新动作，同一次动作的重复原生通知不会反复重启它。
- 商店和休息点也使用连续动画；选人界面保留独立立绘与深海背景。
- 纹理与骨骼数据共享加载；删除运行时不再需要的两套旧图集加载，避免重复占用纹理内存。

本版使用自制加权网格绑定，身体与肢体在同一张立绘上形变；猎手包的美术分层、骨骼和关键帧没有移植。动作幅度针对该图的结构制作，不能据此承诺与猎手完全相同的肢体表演。实际显示帧率仍受游戏和机器性能影响。

旧机器人骨骼仍保留，供游戏的命中框、动画时长查询、事件和原生等待使用；新骨骼仅显示外观。原数值、游戏任务、存档模型、角色 ID 与 RNG 不修改。

## 构建与检查

工程内部使用 Roslyn 4.14.0，引用本机游戏自带的 .NET 9、GodotSharp 与 Harmony。没有 SDK 时可运行：

```powershell
# 首次准备固定版本的公开编译和反编译工具。
.\tools\bootstrap.ps1

# 只写工程内的 assets、preview、dist 和 work。
python .\tools\make_rig.py
.\build.ps1
.\tools\verify.ps1
.\tools\verify_harmony.ps1
python .\tools\validate_assets.py

# 用游戏引擎运行独立的临时验证 PCK，没有加载游戏主工程。
python .\tools\verify_spine.py
python .\tools\validate_rig.py
# 可选：用原生采样的软件渲染检查图。生成绑定/检查/渲染使用 SciPy、OpenCV、Pillow 和 NumPy。
python .\tools\render_puppet.py
python .\tools\package.py
```

构建脚本不会启动游戏；verify_spine.py 会以 headless 方式启动本机引擎，并明确传入自建验证包。测试脚本与骨骼数据均属于本工程，日志和结果写在 work 内。

安装了 .NET 9 SDK 也可编译 DeepSeekMaid.csproj，输出中的 animation 目录必须与 DLL 一起保留。Python 绑定、检查及渲染使用 SciPy、OpenCV、Pillow 和 NumPy。

## 配置

DeepSeekMaid.cfg 在模组 DLL 旁边。可分别关闭人物、卡面、特效、充能球、菜单以及选人背景；也可调整人物高度、特效强度、同时显示数量和每次命中的粒子数。修改后重启游戏。

本次更新请连同配置一起复制，才能使用新的默认 `sprite_height=300.0`；保留旧配置中的 260 会继续使用原尺寸。

默认严格保护游戏版本。若 release_info.json 不再是 v0.111.0，模组将跳过初始化并写入日志；需要核对新 beta 的接口后重新适配。关闭保护不能代替兼容性修复。
